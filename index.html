阅读规则：证据先于结论

“未找到公开记录”不自动等于“事情不存在”。本页使用分级表述：属实、属实但表述扩大、未找到公开实证、存疑待证。每条都标注来源日期、来源类型与复核动作；当事人提供可验证反证后，应更新对应条目。

CLAIM / RECORD / CHECK

宣传主张与公开记录

不要只看一张海报。点开原始链接，优先阅读官方页面、赛事方记录和数据库字段，再判断“个人、团队、公司、任职单位”到底是哪一个主体。

“吉林大学 CTF 战队指导教师”

海报与简介以现在时展示该指导身份，并指向 2019—2020 年。

第八届 XCTF 总决赛战队巡礼称 Spirit 战队“在指导教师康健老师的带领下成立于 2019 年”。这形成需要解释的同期记录差异。

报告所列四校官网未找到对应聘任新闻或公示；其中部分聘期已经届满，苏州科技大学聘书还存在校名/学科表述、用章与聘期等需要校方确认的疑点。

04
未找到公开实证漏洞赏金 / CVE

“拥有多个 IoT 官方 CVE 漏洞编号”

使用“多个编号”这一概括，但宣传材料没有列出可逐条查询的编号清单。

报告检索未找到与该姓名及网络 ID 对应的公开 CVE 署名。唯一常被关联到书中案例的 CVE-2019-25487，其原始 Exploit-DB 条目作者署名为 k1nm3n.aotoi。

复核动作：要求提供编号清单，再逐条在 CVE.org / NVD 查看发现者、致谢与引用来源字段。没有编号清单，就无法验证“多个”到底指什么。

偷换主体 / 表述扩大专利 / WAF

“国家发明专利”与技术性质

将专利作为个人技术光环，并在物联网安全语境中传播。

范围与主体需拆开领域 / 实际分享

“物联网、车联网、机器人安全”与公开内容范围

把多个技术领域并列放入专家定位。

5-MINUTE CHECK

合作或报名之前，先做五分钟核验

  1. 要编号：要求对方列出“多个 CVE”的具体编号。
  2. 看主体：团队奖项、公司项目、职务发明，不自动等于个人荣誉。
  3. 看期限：聘书、证书是否已届满，宣传是否仍使用现在时。
  4. 看官方：高校聘任优先找校方公告、新闻或学院确认。
  5. 留证据：保存网页 URL、页面日期和截图，不传播不必要的个人信息。
