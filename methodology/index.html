HOW WE VERIFY / 方法

核验方法与证据边界

目标不是替读者下判决，而是把宣传中的头衔变成任何人都能重做的检索步骤。

本站如何下结论

  1. 先固定宣传原话。 区分“本人自述”“第三方转述”“授予方记录”。
  2. 把复合人设拆成字段。 谁授予、授予谁、哪一年、什么角色、哪条记录、是否仍有效。
  3. 优先原始记录。 学校、赛事方、漏洞库、专利库、平台本人主页优先于自媒体文章。
  4. 保留不确定性。 搜索无结果只写“未检索到公开记录”，不写“绝对不存在”。
  5. 允许反证更新。 新材料必须能由第三方复现，修订会进入更新记录。

本站不做什么

不作刑事、民事或职业资格定性；不公开私人住址、联系方式等无关信息；不鼓励骚扰、围堵、集中举报或对家属与无关人员施压。

为什么保留真实姓名

本页核验的是以真实姓名和网络 ID 对公众传播、用于专业背书的公开主张。姓名用于帮助潜在合作方准确找到核验材料；正文尽量只保留完成主体识别所必需的信息，并对结论设置证据边界。
