# 把宣传翻过去｜公开信息核验索引

这是一个无构建依赖的 GitHub Pages 静态站点。内容以用户提供的脱敏核查材料和其中列出的公开来源为基础，采用“宣传主张 / 公开记录 / 复核动作 / 结论等级”结构。

## 发布前必做

1. 逐个打开页面中的原始链接，确认页面仍存在、内容与摘要一致，并记录访问日期。
2. 将 `robots.txt` 和 `sitemap.xml` 中的 `YOUR-USERNAME`、`YOUR-REPOSITORY` 替换为真实 GitHub Pages 地址。
3. 对姓名、网络 ID、截图、页面标题和事实表述进行一次隐私与法律审阅；删除非必要个人信息。
4. 确保每个带判断色彩的句子都能回指来源，并保留“存疑/未找到公开实证”等边界表述。

## GitHub Pages

将本目录内容放入仓库根目录，进入 **Settings → Pages**，选择从部署分支发布。GitHub 官方文档说明，静态站点可从分支根目录或 `/docs` 目录发布；公开发布前不要把敏感资料放进仓库。

## SEO 说明

页面已包含语义化标题、可读正文、canonical 友好的相对结构、robots.txt、sitemap.xml、Open Graph 元数据和 Article JSON-LD。结构化数据不保证搜索结果展示；不要使用关键词堆砌、隐藏文字、虚假评价或批量重复页面。
